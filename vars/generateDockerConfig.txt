Generate a `~/.docker/config.json` file containing authentication data to authenticate against DockerHub.

Parameters:

* `dockerHubSecretId`: The id of the Jenkins text credentials (defined at https://ci.xwiki.org/credentials/)
  containing the Personal Access Token of the DockerHub user (e.g. `xwikici`, which is what `xwikiBuild` uses by
  default). Nothing is done if it's null or empty.
* `dockerHubUserId`: The id of the DockerHub user (e.g. `xwikici`)
